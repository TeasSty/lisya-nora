# Иконки комнат карты норы

Источник части иконок: [Game-icons.net](https://game-icons.net/)  
Лицензия: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)

Обязательная атрибуция авторам (требование лицензии):

| Файл | Комната | Иконка | Автор |
|------|---------|--------|-------|
| `jewelry.svg` | Украшения | [ring-box](https://game-icons.net/1x1/delapouite/ring-box.html) | Delapouite |
| `forge.svg` | Работы кузнеца | [anvil](https://game-icons.net/1x1/lorc/anvil.html) | Lorc |
| `dolls.svg` | Куклы коллекционные | [squirrel](https://game-icons.net/1x1/delapouite/squirrel.html) | Delapouite |
| `ceramics.svg` | Керамика | [amphora](https://game-icons.net/1x1/delapouite/amphora.html) | Delapouite |

Собственные силуэты (не Game-icons): `seeds.svg`, `perfume.svg`, `wood.svg`, `candles.svg`, `highlights.svg`.

Устаревшие файлы (`curiosities`, `charms`, `decor`, `misc`) оставлены для совместимости со старыми ссылками.

«Весь магазин» использует фирменный `FoxMark` (собственный логотип), не из этого набора.

Файлы скачаны как SVG (B/T, чёрный на прозрачном); `fill` заменён на `currentColor` для тона terracotta сайта.
